# 성성호수공원 재현 — 작업 인수인계

브랜치: `claude/seongseong-lake`. dev 브랜치·main 은 건드리지 않는다. 단계마다 커밋·푸시.

## 목표 (사용자 요청)
- 성성호수공원 **지도 사진 그대로의 재현**. 호수가 섬(지도) 중심에 크게.
- 주변 **입주 예정 아파트** 도면·동별 평수·집 구조를 따와서 "성성호수공원에 사는 느낌".
- 주민집은 없앤다(주민은 아파트에 사는 것처럼). 상점·식당은 나중에 현대식으로 재탄생 예정.

## 확정된 결정
| 항목 | 결정 |
|---|---|
| 섬 크기 | 그대로 (±100m, 바닷가 9m → 풀밭 약 ±91m) |
| 호수 크기 | 실제의 **1/10** (약 86×90m), 섬 정중앙 (바깥 사각형 가운데 = (0, 0)) |
| 살 수 있는 단지 | e편한세상 성성호수공원 101~113동 (지도 배치, 10층×2호 = 260호) |
| 샘플 단지 (겉모습만) | 엘리프 1BL 101~105 · 아이파크시티 5단지 502~507 · 6단지 601~609 · 더샵천안라크원(예정 부지, 줄 배치) · 북쪽 업성 기존 단지 — 다음에 단지별로 다듬는다 |
| 평형 | 84A·84B·84C·84D·105·113·125·175·191 (㎡ 기준 타입명). 실제 구조는 **84A·105·125 완료**, 나머지는 예전 84㎡ 평면(34·35)을 임시로 씀 |

## 완료 (커밋 순)
1. **호수** — `spots.json`: seongseong = 1/10 윤곽 202점 + 여울 둘(꼬리 여울, 남쪽 물굽이), lake = 서쪽 연못 36점(id·물고기 31종·갈대 여울 유지). 거리 그림 0.25m/칸.
2. **생활권 이전** — 호수 남쪽(z 55~75)에 광장(0,66)·상점·박물관(−26,62)·식당(26,60)·동사무소(−58,62). 스폰·거울·이벤트 상인·선착장(17.8,35)·떨어지는 물건 자리.
3. **단지** — `apartments.json` v2 (buildings: x,z,yaw,w,d / gate / samples). 지도 캡처를 호수 윤곽으로 정합(IoU 0.97)해 동 위치·방향을 옮김. ApartmentSite·서버 towerRect·공동현관(lobby) 방향 대응. 집 안 격자는 섬 남쪽 바깥(z 215~), 이동 경계 600m.
4. **공원·길·나무·주민** — 호수 둘레길(윤곽 3.2m 바깥)·연못 둘레길·업성수변로·연결로, 방문자센터(e편한세상 서쪽)·정자(남쪽 물굽이)·벤치 14개, 나무 33그루 이전, 주민 house 제거·산책길 이전, 바닥 그림 재생성, 광장 가로등·플레이어 시작 위치.
5. **테스트** — 서버 130개 통과. 클라 e2e 는 social·island 를 빼고 통과(아래 참고).
6. **평면도** — `floorplans.json` 84a·105·125 (scale = 전용면적으로 맞춤, 방 종류 pantry·aircon·alpha 추가).

## 원본·도구
- `tools/art/data/lake_outline_real_m.json`: 지도에서 딴 실제 윤곽(미터). 1/10 변환: `polygons/10` → 큰 호수 바깥 사각형 가운데를 (0,0)으로 → approxPolyDP(0.35m, 연못 0.2m) → Chaikin 1회.
- 윤곽·여울을 바꾸면 `python3 tools/art/gen_lake_sdf.py` → `python3 tools/art/gen_ground.py` 순서로 다시 돌린다 (길·광장을 바꿔도 gen_ground).
- 서버 데이터가 바뀌면 `node server/tools/make_test_snapshot.js` (앱 테스트 서버 입장 정보).

## 검증 방법
- 서버: `cd server && npm ci && npm test`
- 클라: `GODOT=<godot 4.5> tests/run_<이름>_e2e.sh` (economy, fishing, coop, island, village, events, home, shop, mirror, net, social, test_server, title)
- 렌더: `xvfb-run -a -s "-screen 0 1280x960x24" $GODOT --path . --rendering-driver vulkan --rendering-method mobile res://tools/art_preview.tscn -- --what=village --cam=x,y,z --at=x,y,z --player=x,y,z --out=a.png`
  (월드 커브는 플레이어 기준이라 먼 곳은 `--player` 로 플레이어를 그쪽에 둔다). 렌더 뒤 `.import` 파일 변경은 되돌린다.
