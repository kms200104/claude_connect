솔바람 마을 · 테스트 서버 (Windows)

1. 압축을 통째로 푼다 (폴더 안의 node, server, data 폴더를 그대로 둔다).
2. START_SERVER.bat 을 더블클릭한다.
   - 처음 켤 때 Windows 방화벽 창이 뜨면 "허용"을 누른다 (폰이 PC 에 접속하려면 필요).
   - 창에 폰에 적을 주소가 나온다:  ws://192.168.x.x:8080
3. 폰에 solbaram.apk 를 설치하고, 같은 와이파이에서 앱의 서버 주소 칸에 위 주소를 적고 "방 만들기".
   두 번째 폰은 같은 주소 + 방 코드로 "들어가기".
4. 테스트 도구가 켜져 있다: 휴대폰(게임 안) → 설정 → 맨 아래 "테스트: 2000억 솔 받기".
5. 끄려면 서버 창을 닫는다. 저장은 saves 폴더에 남는다 (지우면 처음부터).

- git 이나 Node.js 를 따로 설치할 필요가 없다 (node\node.exe 포함).
- 앱과 서버는 같은 버전이어야 한다. "앱 버전이 서버와 달라요"가 뜨면 같은 때 만든 APK 와 서버 묶음을 함께 쓴다.
- 실제 서비스용 서버에서는 테스트 도구를 켜지 않는다 (DEV_TOOLS 를 설정하지 않으면 꺼져 있다).
